# investiment_desafio_um
Projeto de desafio: Ferramenta de Controle de Investimentos com Excel.

  Com base nas orientações fornecidas em aula, desenvolvemos a planilha de Simulação de Investimento com o proposito de ser visualmente fácil de interpretar as informações almejadas. Previamente, também foi desenvolvido a identidade visual da empresa InvestMente, juntamente com a sua logo.

  Em relação as tabelas criadas, utilizamos as informações básicas apresentadas pelo professor, mas claro, deixando-as todas com as minhas características, nas cores, disposição das informações e aquele jeitinho de deixar algo mais íntimo para o cliente, tendo o campo nome para deixar cada análise única.

  Pensado por esse caminho, as tabelas e orientação da página foram posicionadas desta forma, visando ao final do atendimento, o cliente poder levar impresso ou de modo portable document a análise solicitada por ele.
  
  As fórmulas, renomeações de células aplicadas em campos distintos, compõe o conjunto de funções para deixas a planilha automatizada, facilitando seu manuseio. Para os valores não saírem negativo, colocamos a formula ABS concatenada com a função. 
 
  Na tabela Período estimado, na coluna G, foi aplicado uma formatação de rótulos para que a célula continuasse como número para ser utilizado na formulas, mas que graficamente a palavra anos complementasse o número dando contesto a informação solicitada. 

  No geral a atividade foi desenvolvida de forma objetiva.
